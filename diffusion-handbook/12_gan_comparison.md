# 第12章 生成对抗网络（GAN）：理论、发展与扩散模型的对话

> 在扩散模型崛起之前，GAN 统治了图像生成领域近十年。理解 GAN，不仅是为了了解历史，更是为了从两种截然不同的哲学中，深入理解"生成模型"这个问题的本质。这一章我们将走进 GAN 的世界，然后让它与扩散模型展开一场对话。

---

## 12.1 GAN 的核心思想

### 12.1.1 一个绝妙的比喻：伪造者与鉴定师

想象一个伪造名画的犯罪团伙：

- **伪造者（Generator, G）**：努力画出逼真的假画，骗过鉴定师
- **鉴定师（Discriminator, D）**：努力分辨真画和假画

```
训练过程：
┌──────────┐    假画     ┌──────────┐
│  伪造者 G │ ──────────→ │ 鉴定师 D │
│ (生成器)   │            │ (判别器)   │
└──────────┘            └──────────┘
                              │
                    "这是假的！" / "这是真的"
                              │
                     ┌────────┴────────┐
                     ▼                 ▼
              G 学习改进造假      D 学习提高鉴别
                     │                 │
                     └────────┬────────┘
                              ▼
                     双方都越来越强
                     → G 生成的画越来越逼真
```

**纳什均衡**：当 G 的画完美到 D 无法分辨（50% 概率猜对），训练达到平衡。

### 12.1.2 数学形式化

**极小极大博弈（Minimax Game）**：

$$\min_G \max_D \, V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$$

| 符号 | 含义 |
|------|------|
| $G(z)$ | 生成器：将噪声 $z$ 映射为假数据 |
| $D(x)$ | 判别器：输出 $x$ 为真实数据的概率 |
| $p_{\text{data}}$ | 真实数据分布 |
| $p_z$ | 噪声分布（通常为标准高斯） |
| $V(D, G)$ | 博弈的价值函数 |

**两个玩家的目标**：
- **判别器 D**：最大化 $V$——正确区分真假（让 $D(x_{\text{real}}) \to 1$，$D(x_{\text{fake}}) \to 0$）
- **生成器 G**：最小化 $V$——骗过判别器（让 $D(G(z)) \to 1$）

### 12.1.3 最优判别器

**定理**：给定固定的生成器 $G$，最优判别器为：

$$D^*_G(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_G(x)}$$

**证明**：

将 $V(D, G)$ 对 $D(x)$ 求导并令其为 0：

$$\frac{\partial V}{\partial D(x)} = \frac{p_{\text{data}}(x)}{D(x)} - \frac{p_G(x)}{1 - D(x)} = 0$$

解得 $D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_G(x)}$。

**直觉**：最优判别器在每一点 $x$ 上，输出的是"真实数据概率"占"总概率"的比例。如果 $p_{\text{data}}(x) = p_G(x)$，则 $D^*(x) = 0.5$——无法区分。

### 12.1.4 全局最优：$p_G = p_{\text{data}}$

将最优判别器代入价值函数：

$$\begin{aligned}
V(D^*_G, G) &= \mathbb{E}_{p_{\text{data}}}\left[\log \frac{p_{\text{data}}}{p_{\text{data}} + p_G}\right] + \mathbb{E}_{p_G}\left[\log \frac{p_G}{p_{\text{data}} + p_G}\right] \\
&= -\log 4 + 2 \cdot D_{JS}(p_{\text{data}} \| p_G)
\end{aligned}$$

其中 $D_{JS}$ 是 **Jensen-Shannon 散度**：

$$D_{JS}(p \| q) = \frac{1}{2}D_{KL}\left(p \left\| \frac{p+q}{2}\right.\right) + \frac{1}{2}D_{KL}\left(q \left\| \frac{p+q}{2}\right.\right)$$

**关键结论**：

- 当 $p_G = p_{\text{data}}$ 时，$D_{JS} = 0$，$V$ 取最小值 $-\log 4$
- GAN 的训练目标等价于最小化真实分布与生成分布之间的 JS 散度
- 这就是 GAN 的"隐式"分布匹配——它不直接计算分布之间的距离，而是通过对抗训练隐式地最小化它

## 12.2 GAN 的训练困境与数学分析

### 12.2.1 梯度消失问题

**问题**：在训练初期，生成器很差，$p_G$ 与 $p_{\text{data}}$ 几乎没有重叠。此时最优判别器 $D^*$ 非常自信（输出接近 0 或 1），导致生成器的梯度几乎为 0。

**数学解释**：当 $D^*(G(z)) \to 0$ 时：

$$\nabla_G \log(1 - D(G(z))) \to 0$$

生成器收到的信号太弱，无法学习。

**Goodfellow 的解决方案**：将生成器目标从 $\min_G \log(1 - D(G(z)))$ 改为 $\max_G \log D(G(z))$——在训练初期，$D(G(z))$ 接近 0 时，$\log D(G(z))$ 的梯度很大。

### 12.2.2 模式坍塌（Mode Collapse）

**问题**：生成器可能只学会生成少数几种样本，而忽略数据分布的其他模式。

```
真实数据分布：          生成器分布（模式坍塌）：
  ● ● ● ● ● ●            ● ● ●
  ●       ●
  ●       ●               （只覆盖了一个模式）
  ● ● ● ● ● ●
```

**原因**：生成器的目标只是骗过判别器，而不是覆盖整个数据分布。如果一种假画已经能骗过判别器，生成器就没有动力去探索其他风格。

**数学解释**：JS 散度只关心两个分布是否不同，不关心生成分布是否覆盖了所有模式。生成器可以只在一个模式上与真实分布匹配，就能获得很低的 JS 散度。

### 12.2.3 训练不稳定性

GAN 的训练是两个神经网络的博弈，很难达到纳什均衡：

- 判别器太强 → 生成器梯度消失
- 判别器太弱 → 生成器缺乏有效信号
- 两者交替提升 → 可能振荡而不收敛

**与扩散模型的对比**：扩散模型的训练是单调的——损失函数稳定下降，不存在博弈平衡的问题。

## 12.3 GAN 的发展历程

### 12.3.1 第一代：原始 GAN（2014）

**论文**：Generative Adversarial Nets（Goodfellow et al., 2014）

- 提出了对抗训练框架
- 使用全连接网络
- 只能生成低分辨率图像（如 28×28 的 MNIST）
- 训练极不稳定

### 12.3.2 DCGAN（2015）

**论文**：Unsupervised Representation Learning with Deep Convolutional GANs（Radford et al., 2015）

关键改进：
- 使用卷积网络替代全连接网络
- 提出稳定的架构设计原则（批量归一化、ReLU/LeakyReLU、步进卷积）
- 可以生成 64×64 的图像

### 12.3.3 WGAN（2017）

**论文**：Wasserstein GAN（Arjovsky et al., 2017）

**核心贡献**：用 **Wasserstein 距离**（也叫 Earth Mover's Distance）替代 JS 散度。

**Wasserstein 距离**：

$$W(p_{\text{data}}, p_G) = \inf_{\gamma \in \Pi(p_{\text{data}}, p_G)} \mathbb{E}_{(x,y) \sim \gamma}[\|x - y\|]$$

**直觉**：把概率分布想象成两堆土，Wasserstein 距离就是"把一堆土移到另一堆土的位置"所需的最小工作量。

**Wasserstein 距离 vs JS 散度**：

| 性质 | JS 散度 | Wasserstein 距离 |
|------|---------|-----------------|
| 两个不重叠分布 | $D_{JS} = \log 2$（常数） | $W > 0$（有意义） |
| 梯度 | 不重叠时为 0 | 始终有意义的梯度 |
| 连续性 | 不连续 | Lipschitz 连续 |

**WGAN 的判别器（critic）**：

$$W(p_{\text{data}}, p_G) \approx \max_{\|f\|_L \leq 1} \left[\mathbb{E}_{p_{\text{data}}}[f(x)] - \mathbb{E}_{p_G}[f(x)]\right]$$

其中 $\|f\|_L \leq 1$ 是 Lipschitz 连续性约束，通过权重裁剪（weight clipping）或梯度惩罚（gradient penalty）实现。

**WGAN 的优势**：
- 训练更稳定
- 损失函数与生成质量相关（可以用来监控训练）
- 缓解模式坍塌

### 12.3.4 条件 GAN（cGAN, 2014-2016）

**论文**：Conditional Generative Adversarial Nets（Mirza & Osindero, 2014）

在生成器和判别器中都加入条件信息 $y$（如类别标签、文字描述）：

$$\min_G \max_D \, V(D, G) = \mathbb{E}_{x \sim p_{\text{data}}}[\log D(x|y)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z|y)|y))]$$

### 12.3.5 Progressive GAN（ProGAN, 2018）

**论文**：Progressive Growing of GANs for Improved Quality, Stability, and Variation（Karras et al., 2018）

**核心思想**：从低分辨率开始训练，逐步增加分辨率。

```
4×4 → 8×8 → 16×16 → 32×32 → 64×64 → 128×128 → 256×256 → 512×512 → 1024×1024
```

每增加一层，先平滑过渡（淡入），再正常训练。这种渐进式训练极大地提高了高分辨率图像的生成质量。

### 12.3.6 StyleGAN（2019-2021）

**论文**：A Style-Based Generator Architecture for Generative Adversarial Networks（Karras et al., 2019）

**核心创新**：将生成器改为"风格调制"架构。

```
传统 GAN 生成器：                StyleGAN 生成器：
z → G(z) → 图像               z → Mapping Network → w
                                     │
                                ┌────┼────┐
                                ▼    ▼    ▼
                               AdaIN AdaIN AdaIN
                                │    │    │
                              4×4  8×8  ... 1024×1024
                               常数输入 → 逐层调制 → 图像
```

**风格调制（AdaIN）**：

$$\text{AdaIN}(h, w) = w_\gamma \cdot \frac{h - \mu(h)}{\sigma(h)} + w_\beta$$

其中 $w = (w_\gamma, w_\beta)$ 是从潜编码 $w$ 生成的风格参数。

**StyleGAN 的关键特性**：
- **风格混合**：不同层使用不同的 $w$，可以独立控制粗粒度（姿态、脸型）和细粒度（发色、肤色）特征
- **随机变化**：每层加入随机噪声，控制随机细节（雀斑、发丝）
- **解耦潜空间**：$w$ 空间比 $z$ 空间更解耦，每个维度控制更独立的特征

**StyleGAN2（2020）**：移除伪影、改进架构、路径长度正则化
**StyleGAN3（2021）**：解决"纹理粘连"问题，实现旋转等变换的一致性

### 12.3.7 GAN 的发展时间线

```
2014  GAN（Goodfellow）—— 对抗训练框架
  │   cGAN（Mirza & Osindero）—— 条件生成
  │
2015  DCGAN（Radford et al.）—— 卷积架构
  │
2016  InfoGAN（Chen et al.）—— 解耦表示学习
  │   Pix2Pix（Isola et al.）—— 图像翻译
  │
2017  WGAN（Arjovsky et al.）—— Wasserstein 距离
  │   CycleGAN（Zhu et al.）—— 无配对图像翻译
  │   BEGAN（Berthelot et al.）—— 均衡对抗
  │
2018  ProGAN（Karras et al.）—— 渐进式训练
  │   BigGAN（Brock et al.）—— 大规模训练
  │   SAGAN（Zhang et al.）—— 自注意力机制
  │
2019  StyleGAN（Karras et al.）—— 风格调制架构
  │
2020  StyleGAN2（Karras et al.）—— 改进伪影
  │   Projected GAN（Sauer et al.）—— 高效训练
  │
2021  StyleGAN3（Karras et al.）—— 旋转一致性
  │
2022  GigaGAN（Kang et al.）—— 十亿参数 GAN
  │   GAN 受扩散模型冲击，研究重心转移
  │

```

## 12.4 GAN 与扩散模型的深度对比

### 12.4.1 哲学层面的对比

| 维度 | GAN | 扩散模型 |
|------|-----|---------|
| **核心哲学** | 对抗：两个网络博弈 | 重建：学习逆转噪声过程 |
| **分布匹配方式** | 隐式（通过对抗训练） | 显式（通过最大似然/ELBO） |
| **训练信号来源** | 判别器的反馈 | 数据本身的噪声结构 |
| **生成方式** | 一步映射 $G(z) \to x$ | 迭代去噪 $x_T \to x_0$ |
| **理论保证** | 纳什均衡（难以保证收敛） | ELBO 单调下降（训练稳定） |

### 12.4.2 数学框架的对比

**GAN 的数学框架**：

$$\min_G \max_D \, V(D, G)$$

- 优化目标：JS 散度 / Wasserstein 距离
- 训练方式：交替优化两个网络
- 收敛性：难以保证，依赖超参数平衡

**扩散模型的数学框架**：

$$\min_\theta \, \mathbb{E}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

- 优化目标：ELBO / 噪声预测 MSE
- 训练方式：单一网络，直接优化
- 收敛性：损失单调下降，训练稳定

### 12.4.3 生成质量的对比

| 指标 | GAN（StyleGAN2/3） | 扩散模型（SD/SDXL） |
|------|-------------------|-------------------|
| FID（ImageNet 128×128） | ~2.0 | ~2.0 |
| FID（ImageNet 256×256） | ~3.0 | ~3.5 |
| FID（ImageNet 512×512） | ~4.0 | ~5.0 |
| 感知锐度 | 更锐利 | 略模糊 |
| 多样性 | 较差（模式坍塌风险） | 更好 |
| 条件控制 | 需要额外设计 | Classifier-free Guidance |

**关键观察**：
- 在 FID 指标上，GAN 和扩散模型已经相当
- GAN 生成的图像通常更"锐利"，扩散模型生成的图像有时略"模糊"
- 扩散模型的多样性显著优于 GAN
- 扩散模型的可控性远优于 GAN

### 12.4.4 采样速度的对比

| 方法 | 采样步数 | 采样时间（512×512） |
|------|---------|-------------------|
| GAN | 1 步 | ~10ms |
| DDPM | 1000 步 | ~60s |
| DDIM | 50 步 | ~3s |
| 一致性模型 | 1 步 | ~10ms |
| LCM | 2-4 步 | ~50ms |

**GAN 的最大优势**：一步生成，速度极快。这是 GAN 在实时应用中仍然被使用的主要原因。

### 12.4.5 训练难度对比

| 方面 | GAN | 扩散模型 |
|------|-----|---------|
| 超参数敏感性 | 极高（G/D 平衡、学习率、架构） | 较低 |
| 训练稳定性 | 不稳定（模式坍塌、振荡） | 稳定 |
| 收敛判断 | 困难（FID 不一定下降） | 简单（损失单调下降） |
| 训练时间 | 较短（但需要调参） | 较长（但几乎不需要调参） |
| 数据效率 | 较低 | 较高 |

### 12.4.6 可控性对比

| 控制方式 | GAN | 扩散模型 |
|---------|-----|---------|
| 类别条件 | cGAN | 条件扩散 |
| 文本条件 | 需要复杂设计 | Classifier-free Guidance |
| 图像编辑 | StyleGAN 潜空间编辑 | Inpainting、ControlNet |
| 风格迁移 | CycleGAN、StarGAN | IP-Adapter、风格参考 |
| 精细控制 | InterFaceGAN、GANSpace | ControlNet、T2I-Adapter |

**扩散模型在可控性上的优势**：Classifier-free Guidance 提供了一种统一且高效的条件控制方式，无需额外训练分类器或修改架构。

## 12.5 两种范式的深层差异

### 12.5.1 隐式 vs 显式概率模型

**GAN 是隐式模型**：

- 生成器定义了一个从 $z$ 到 $x$ 的映射 $G(z)$
- 可以采样，但无法计算 $p_G(x)$（概率密度）
- 无法计算对数似然、KL 散度等

**扩散模型是显式模型**：

- 定义了完整的概率分布 $p_\theta(x_0)$
- 可以计算（或近似计算）对数似然
- 可以计算 KL 散度、互信息等信息论量

**后果**：

| 能力 | GAN | 扩散模型 |
|------|-----|---------|
| 采样 | ✓ | ✓ |
| 密度估计 | ✗ | ✓ |
| 似然计算 | ✗ | ✓（近似） |
| 插值 | ✓（潜空间） | ✓（ODE 轨迹） |
| 组合概率 | ✗ | ✓ |

### 12.5.2 模式覆盖 vs 模式寻求

**GAN 是模式寻求（Mode-seeking）**：

JS 散度的性质使得 GAN 倾向于找到真实分布的一个子集并集中生成。这导致：
- 生成质量高（集中在高质量模式上）
- 多样性差（可能遗漏模式）

**扩散模型是模式覆盖（Mode-covering）**：

最大似然（ELBO）的性质使得扩散模型试图覆盖真实分布的所有模式。这导致：
- 多样性好（覆盖所有模式）
- 可能在某些模式上质量略低

```
真实分布：     GAN 覆盖：     扩散模型覆盖：
  ● ● ● ●      ● ●           ● ● ● ●
  ●       ●    ● ●           ●   ○   ●
  ●       ●    （遗漏了       （覆盖了所有
  ● ● ● ●      两侧的模式）   模式，但某些
                               质量可能略低）
```

### 12.5.3 训练动态：博弈 vs 优化

**GAN 的训练动态**：

- 两个网络的博弈，类似两人零和博弈
- 可能振荡、不收敛
- 需要精心平衡 G 和 D 的训练
- 训练曲线不平稳

**扩散模型的训练动态**：

- 单一网络的优化问题
- 损失函数单调下降
- 训练曲线平稳
- 几乎不需要调参

## 12.6 最新研究：融合与超越

### 12.6.1 GAN 的复兴：结合扩散模型的优势

**Consistency GAN（ConGAN, 2024）**：

将一致性模型的"自一致性"约束引入 GAN，实现少步生成：

$$f_\theta(x_t, t) = f_\theta(\hat{x}_{t'}, t'), \quad \forall t, t'$$

结合 GAN 的判别器提供高质量信号，一致性约束保证少步收敛。

### 12.6.2 扩散蒸馏用 GAN 损失

**SDXL Turbo / LCM-LoRA（2023-2024）**：

在扩散模型的蒸馏过程中加入 GAN 损失，提升少步生成的质量：

$$\mathcal{L} = \mathcal{L}_{\text{diffusion}} + \lambda \cdot \mathcal{L}_{\text{GAN}}$$

- $\mathcal{L}_{\text{diffusion}}$：保证与原始扩散模型的一致性
- $\mathcal{L}_{\text{GAN}}$：提升少步生成的锐度和真实感

**效果**：2-4 步生成质量显著提升，接近 GAN 的速度。

### 12.6.3 GigaGAN：大规模 GAN 的回归

**GigaGAN（Kang et al., 2023）**：

- 十亿参数的 GAN，首次在大规模上与扩散模型竞争
- 引入文本条件、多尺度判别器、风格注入
- 生成质量接近 Stable Diffusion，速度快 100 倍
- 但训练成本极高，灵活性仍不如扩散模型

### 12.6.4 Adversarial Diffusion：对抗训练提升扩散模型

**ADD（Adversarial Diffusion Distillation, 2024）**：

Stability AI 提出的方法，在蒸馏扩散模型时使用对抗损失：

- 教师模型：预训练的扩散模型
- 学生模型：少步模型
- 判别器：提供"真实感"信号
- 结果：1-4 步生成高质量图像

**训练目标**：

$$\mathcal{L} = \mathcal{L}_{\text{SDS}} + \lambda_{\text{adv}} \mathcal{L}_{\text{adv}} + \lambda_{\text{reg}} \mathcal{L}_{\text{reg}}$$

其中 SDS 是扩散蒸馏损失，$\mathcal{L}_{\text{adv}}$ 是对抗损失。

### 12.6.5 一致性轨迹模型（CTM, 2024）

**Consistency Trajectory Model（Kim et al., 2024）**：

统一一致性模型和扩散模型：
- 在 ODE 轨迹上的任意两点之间建立一致性映射
- 支持任意步数采样（1 步到 1000 步）
- 结合 GAN 损失提升 1 步生成质量

### 12.6.6 DMD（Distribution Matching Distillation, 2024）

**Distribution Matching Distillation（Yin et al., 2024）**：

用分布匹配（而非逐步蒸馏）训练少步模型：
- 不需要逐步蒸馏，直接匹配目标分布
- 使用类似 GAN 的对抗框架，但用扩散模型作为判别器
- 1 步生成质量接近 50 步 DDIM

### 12.6.7 最新对比总结（2024-2025）

| 方面 | 纯 GAN | 纯扩散模型 | 融合方法 |
|------|--------|-----------|---------|
| 1 步生成质量 | 中等 | 差 | **优秀** |
| 多步生成质量 | 好 | 优秀 | 优秀 |
| 训练稳定性 | 差 | 好 | 中等 |
| 采样速度 | 极快 | 慢 | 快 |
| 多样性 | 差 | 好 | 好 |
| 可控性 | 有限 | 强 | 强 |
| 理论基础 | 博弈论 | 概率论 | 混合 |

## 12.7 从数学角度看两种范式的本质

### 12.7.1 GAN 的数学本质：变分下界的对偶

**定理**（Goodfellow et al., 2014；Nowozin et al., 2016）：

GAN 的训练目标等价于 $f$-散度的变分下界：

$$D_f(p_{\text{data}} \| p_G) = \max_{T} \left[\mathbb{E}_{p_{\text{data}}}[T(x)] - \mathbb{E}_{p_G}[f^*(T(x))]\right]$$

其中 $f^*$ 是 $f$ 的凸共轭函数，$T$ 是判别器学到的函数。

| GAN 变体 | 对应的 $f$-散度 |
|----------|----------------|
| 原始 GAN | Jensen-Shannon 散度 |
| WGAN | Wasserstein 距离 |
| EBGAN | 能量距离 |
| LSGAN | Pearson $\chi^2$ |

### 12.7.2 扩散模型的数学本质：分数匹配

扩散模型的训练目标等价于去噪分数匹配：

$$\mathcal{L}_{\text{DSM}} = \mathbb{E}_{t, x_0, x_t}\left[\|s_\theta(x_t, t) - \nabla_{x_t}\log p_t(x_t|x_0)\|^2\right]$$

这是 ELBO 的简化形式，等价于最小化真实 Score 与模型 Score 之间的均方误差。

### 12.7.3 统一视角：从变分到对抗

**变分方法**（扩散模型）：
- 选择一个参数化的近似分布 $q_\theta$
- 最小化 $q_\theta$ 与 $p_{\text{data}}$ 之间的某个散度
- 散度是固定的，优化是单调的

**对抗方法**（GAN）：
- 选择一个参数化的散度估计器 $D_\phi$
- 同时优化 $q_\theta$ 和 $D_\phi$
- 散度本身也在变化，优化是非单调的

**融合方法**的思路：用变分方法保证训练稳定性，用对抗方法提升生成锐度。

## 12.8 实际应用中的选择指南

### 12.8.1 何时选择 GAN

1. **实时生成**：视频流、交互式应用，需要毫秒级响应
2. **超分辨率**：Real-ESRGAN 等方法在超分任务上仍然高效
3. **特定领域**：人脸生成（StyleGAN 系列）仍有优势
4. **资源受限**：GAN 推理只需一次前向传播

### 12.8.2 何时选择扩散模型

1. **高质量多样化生成**：文生图、艺术创作
2. **精确条件控制**：文本引导、布局控制
3. **图像编辑**：Inpainting、风格迁移
4. **科学应用**：分子设计、蛋白质结构预测
5. **密度估计**：需要计算似然的场景

### 12.8.3 何时选择融合方法

1. **少步高质量生成**：需要 1-4 步生成高质量图像
2. **蒸馏加速**：已有扩散模型，需要加速推理
3. **平衡质量与速度**：需要比纯扩散快、比纯 GAN 质量高

## 12.9 本章小结

| 对比维度 | GAN | 扩散模型 |
|---------|-----|---------|
| 核心思想 | 对抗博弈 | 去噪重建 |
| 训练稳定性 | 不稳定 | 稳定 |
| 采样速度 | 极快（1步） | 慢（需加速） |
| 生成多样性 | 较差 | 优秀 |
| 可控性 | 有限 | 强大 |
| 理论基础 | 博弈论、$f$-散度 | 概率论、变分推断 |
| 最新趋势 | 与扩散融合 | 用 GAN 损失加速蒸馏 |

**核心洞察**：GAN 和扩散模型不是对立的，而是互补的。GAN 擅长快速高质量生成，扩散模型擅长稳定训练和精确控制。最新的研究方向正在将两者的优势融合——用扩散模型的训练稳定性保证收敛，用 GAN 的对抗信号提升少步生成的质量。

## 练习与思考

1. **最优判别器**：设 $p_{\text{data}}(x) = \mathcal{N}(0, 1)$，$p_G(x) = \mathcal{N}(1, 1)$。计算最优判别器 $D^*(x)$，并验证当 $x = 0.5$ 时 $D^*(0.5) = 0.5$。

2. **JS 散度**：计算上述两个高斯分布之间的 JS 散度。（提示：$D_{JS}(p\|q) = \frac{1}{2}D_{KL}(p\|\frac{p+q}{2}) + \frac{1}{2}D_{KL}(q\|\frac{p+q}{2})$）

3. **Wasserstein 距离**：对于一维高斯分布 $p = \mathcal{N}(\mu_1, \sigma^2)$ 和 $q = \mathcal{N}(\mu_2, \sigma^2)$，Wasserstein 距离为 $W(p, q) = |\mu_1 - \mu_2|$。验证当 $\mu_1 = 0, \mu_2 = 1$ 时 $W = 1$，而 JS 散度是一个常数（不随 $\mu_1 - \mu_2$ 变化而连续变化）。

4. **思考题**：为什么 GAN 生成的人脸通常比扩散模型更"锐利"？从训练目标的角度分析。（提示：GAN 的判别器关注"看起来是否真实"，而扩散模型的 MSE 损失倾向于平均化）

5. **思考题**：如果让你设计一个融合 GAN 和扩散模型优势的新方法，你会如何设计训练目标？（提示：考虑如何同时获得 GAN 的锐度和扩散模型的多样性）
