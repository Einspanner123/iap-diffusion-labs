# 第1章 引言：为什么用扩散模型学数学？

---

## 1.1 一个改变世界的技术

2022 年 8 月，一幅名为《太空歌剧院》的画作在美国科罗拉多州博览会的美术比赛中获得数字艺术类别的一等奖。这幅画的作者不是人类画家，而是一个叫做 Midjourney 的 AI 系统。它背后的核心技术，就是**扩散模型**。

从那时起，扩散模型以惊人的速度渗透到了我们生活的方方面面：

- **图像生成**：DALL·E、Stable Diffusion、Midjourney 可以根据文字描述生成逼真图片
- **视频生成**：Sora 可以生成高质量的视频片段
- **音乐生成**：MusicLM 等模型可以创作音乐
- **药物设计**：DiffDock 等模型可以预测蛋白质-配体结合结构
- **天气预报**：GenCast 使用扩散模型进行中期天气预报

你可能觉得这些技术离你很遥远，但理解它们需要的数学工具——导数、矩阵、概率分布、贝叶斯定理——恰恰就是你在高中和大学正在学习的内容。

**问题在于：当你只是机械地刷题时，你很难感受到这些工具的力量。**

本手册的目标，就是让你在理解扩散模型的过程中，真正体会到数学的魅力。

## 1.2 什么是扩散模型？一个直觉性的解释

想象你有一张清晰的照片——比如一只猫。

**前向过程（加噪）**：你往照片上逐渐撒"雪花"（噪声），每撒一层，猫的轮廓就模糊一点。撒了足够多层之后，照片变成了一片完全均匀的雪花——你再也看不出这是一只猫。

**反向过程（去噪）**：现在，你训练一个"去噪器"（一个神经网络），让它学会从雪花中一步步恢复出猫的图片。

```
前向过程（加噪）：
  猫的照片 → 稍微模糊 → 更模糊 → 几乎看不清 → 纯噪声
  x₀       x₁          x₂        x₅₀₀           x₁₀₀₀

反向过程（去噪）：
  纯噪声 → 稍微清晰 → 更清晰 → 几乎看清 → 猫的照片
  x₁₀₀₀   x₉₉₉       x₉₉₈      x₅₀₀        x₀
```

这就是扩散模型的核心思想。听起来简单，但要让它真正工作，需要精密的数学设计：

- **每一步加多少噪声？** → 需要设计噪声调度（涉及函数与数列）
- **噪声如何叠加？** → 需要理解高斯分布的叠加性质（涉及概率论）
- **如何从噪声中恢复？** → 需要贝叶斯定理和变分推断（涉及概率论与信息论）
- **如何训练去噪网络？** → 需要推导损失函数（涉及期望、KL 散度、梯度下降）
- **如何加速生成？** → 需要微分方程和数值方法（涉及常微分方程与随机微分方程）

看到了吗？**每一个步骤都对应着具体的数学工具**。这就是为什么扩散模型是学习数学的绝佳载体——你不再是"为了学而学"，而是"为了理解一个真实的技术而学"。

## 1.3 扩散模型的发展简史

了解一段技术的历史，能帮助你理解为什么需要这些数学工具。

### 早期萌芽（2015）

**Sohl-Dickstein et al.** 提出了第一个扩散概率模型，灵感来自物理学中的非平衡热力学。核心思想：模仿墨水在水中的扩散过程，然后学会"逆转"这个过程。

但这个模型效果不好，因为训练方法不够高效。

### Score Matching 时代（2019）

**Song & Ermon** 提出了基于**分数匹配（Score Matching）**的生成模型。核心思想：不直接学习数据分布，而是学习数据分布的**梯度**（即"分数函数"），然后沿着梯度方向采样。

这个方法效果不错，但采样速度很慢。

### DDPM 的突破（2020）

**Ho et al.** 发表了 DDPM（Denoising Diffusion Probabilistic Models），将扩散模型与去噪自编码器联系起来，提出了极其简洁的训练目标：**让神经网络预测每一步加入的噪声**。

DDPM 生成的图像质量首次与 GAN 媲美，而且训练更稳定、多样性更好。

### DDIM 的加速（2021）

**Song et al.** 发现 DDPM 的反向过程可以改写为确定性的 ODE，不需要每一步都加随机噪声。这就是 DDIM，它让采样速度提升了 10-50 倍。

### SDE 统一框架（2021）

**Song et al.** 将 DDPM 和 Score-Based 模型统一到**随机微分方程（SDE）**框架下。这个框架揭示了扩散模型与物理学中随机过程的深层联系，并且提供了更灵活的设计空间。

### Flow Matching（2022-2023）

**Lipman et al.** 提出了 Flow Matching，一种全新的训练范式。不再需要设计噪声调度，只需要回归一个向量场。更简洁、更高效，正在成为新一代扩散模型的基础。

### 大规模应用（2022-至今）

- **Stable Diffusion**：在潜空间中运行扩散模型，大幅降低计算成本
- **DALL·E 2/3**：OpenAI 的图像生成系统
- **Sora**：视频生成模型
- **Consistency Models**：一步生成，速度提升 1000 倍
- **DiT（Diffusion Transformers）**：用 Transformer 替代 UNet，Sora 的基础架构

## 1.4 本手册的数学路线

下面这张表展示了每个数学工具在扩散模型中的具体用途。你不需要现在就理解所有内容——它只是一个"地图"，告诉你每个数学知识点最终会通向哪里。

### 高等数学

| 数学工具 | 在扩散模型中的用途 |
|---------|-------------------|
| 导数与微分 | 描述噪声随时间的变化率 |
| 积分 | 计算概率分布的归一化常数 |
| 偏导数与梯度 | 定义 Score 函数 $\nabla_x \log p(x)$ |
| 链式法则 | 推导反向传播、重参数化技巧 |
| 常微分方程（ODE） | 描述确定性的去噪轨迹（DDIM、Flow Matching） |
| 随机微分方程（SDE） | 描述含噪声的扩散过程（Score SDE） |

### 线性代数

| 数学工具 | 在扩散模型中的用途 |
|---------|-------------------|
| 向量运算 | 图像就是高维向量，噪声是向量的加法 |
| 矩阵乘法 | 线性变换、协方差矩阵 |
| 特征值与特征向量 | 理解协方差矩阵的结构、主成分分析 |
| 正交变换 | 保持距离的变换（旋转、反射） |

### 概率论与统计

| 数学工具 | 在扩散模型中的用途 |
|---------|-------------------|
| 高斯分布 | 扩散模型的核心分布——每一步的噪声都是高斯的 |
| 条件概率 | 从 $x_t$ 推断 $x_{t-1}$ 需要条件分布 |
| 贝叶斯定理 | 推导反向过程的后验分布 |
| 期望与方差 | 计算损失函数、分析噪声强度 |
| 中心极限定理 | 解释为什么高斯分布如此重要 |

### 信息论

| 数学工具 | 在扩散模型中的用途 |
|---------|-------------------|
| 信息熵 | 衡量分布的不确定性 |
| KL 散度 | 衡量两个分布的距离——损失函数的核心 |
| 变分推断与 ELBO | 推导扩散模型的训练目标 |
| 重参数化技巧 | 让梯度能够通过随机采样反向传播 |

## 1.5 学习建议

1. **不要跳过数学推导**：本手册中的每个公式都有推导过程。自己动手推导一遍，比看十遍都有用
2. **理解直觉先于记忆公式**：每个公式引入前，都会先给出直觉解释
3. **关注数学工具的"为什么"**：不只是"怎么算"，更要理解"为什么这样算"
4. **回看高考题**：学完本手册后，你会发现很多高考数学题其实就是这些工具的简化版本
5. **享受过程**：理解前沿技术的数学原理，本身就是一件令人兴奋的事情

## 1.6 符号约定

本手册使用以下数学符号：

| 符号 | 含义 |
|------|------|
| $\mathbb{R}$ | 实数集 |
| $\mathbb{R}^d$ | $d$ 维实向量空间 |
| $\mathcal{N}(\mu, \sigma^2)$ | 均值为 $\mu$、方差为 $\sigma^2$ 的高斯分布 |
| $\mathbb{E}[X]$ | 随机变量 $X$ 的期望 |
| $\text{Var}(X)$ | 随机变量 $X$ 的方差 |
| $\nabla_x f$ | 函数 $f$ 对 $x$ 的梯度 |
| $\Vert\mathbf{v}\Vert$ | 向量 $\mathbf{v}$ 的模（长度） |
| $D_{KL}(q \mid p)$ | 从 $q$ 到 $p$ 的 KL 散度 |
| $\sim$ | "服从分布"，如 $x \sim \mathcal{N}(0,1)$ |
| $\propto$ | "正比于" |
| $\log$ | 自然对数（以 $e$ 为底） |
| $I$ | 单位矩阵 |
| $\text{tr}(A)$ | 矩阵 $A$ 的迹 |
