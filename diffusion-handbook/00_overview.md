# 扩散模型理论学习手册：从数学基础到前沿研究

> **面向高考生的跨学科学习指南**

---

## 本手册的目标

你有没有想过，AI 是怎么"凭空"画出一幅逼真的猫的图片的？

2020 年以来，一类叫做**扩散模型（Diffusion Model）**的算法彻底改变了 AI 生成图像、视频、音乐甚至分子的方式。从 DALL·E 到 Stable Diffusion，从 Sora 到 Midjourney，这些令人惊叹的 AI 背后，核心原理都是扩散模型。

但理解扩散模型，你需要数学。

这本手册的目标不是让你刷更多的题，而是**以扩散模型为具体目标，让你看到高等数学、线性代数、概率论这些"枯燥"的学科，是如何在真实的前沿研究中被使用的**。当你理解了"为什么要学这个"之后，学习本身就会变得有意义。

---

## 你将学到什么

### 数学工具

| 学科 | 核心内容 | 在扩散模型中的角色 |
|------|---------|-------------------|
| 高等数学 | 导数、积分、微分方程、梯度、链式法则 | 描述噪声如何随时间扩散、如何反向去噪 |
| 线性代数 | 向量、矩阵、特征值、线性变换 | 处理高维数据、理解协方差与高斯分布 |
| 概率论与统计 | 随机变量、高斯分布、贝叶斯定理、期望与方差 | 建模噪声过程、推导训练目标 |
| 信息论 | 熵、KL 散度、变分推断 | 推导损失函数、衡量分布之间的距离 |

### 扩散模型理论

| 主题 | 内容 |
|------|------|
| 前向与反向过程 | 噪声如何加入、如何去除 |
| DDPM | 去噪扩散概率模型——一切的开端 |
| DDIM | 确定性采样——让生成速度提升 20 倍 |
| Score-Based Models | 用"分数函数"统一理解扩散模型 |
| SDE 框架 | 用随机微分方程统一离散与连续 |
| Flow Matching | 最新的训练范式——更简洁、更高效 |
| 加速与前沿 | 一致性模型、潜空间扩散、引导生成、DiT 架构 |

## 如何使用本手册

1. **按顺序学习**：章节之间有依赖关系，建议从第 2 章开始顺序阅读
2. **动手推导**：每个关键公式都配有推导过程，请自己拿纸笔验证
3. **关注"为什么"**：每个数学工具引入时，都会说明它在扩散模型中的具体用途
4. **不必一次学完**：内容较多，可以分阶段学习，每学完一章做一个小结
